# Development

[← Back to README](../README.en.md) · [简体中文](development.md) | English

```bash
make test      # unit tests + real SSH end-to-end tests
make lint      # go vet + shellcheck + unit file in sync with the installer
make run       # local, 127.0.0.1:2222
make dist      # cross-compile amd64 / arm64 / armv7 + SHA256SUMS
make bench     # load test
```

Needs Go 1.26.8+ (releases are built with Go 1.26.10, set by the toolchain line in go.mod). To release: change the `VERSION` file (e.g. `0.2.1`) and push to main, or push a `vX.Y.Z` tag; GitHub Actions tests, builds the three architectures and publishes the Release (with `SHA256SUMS`) and the Docker image. Servers upgrade with `sudo vivant-ctl upgrade`. On every push to main, CI verifies dependencies against Go's checksum database, runs govulncheck for published vulnerabilities in dependencies and the Go standard library (again before each release), and runs the installer for real on an Ubuntu machine with systemd: migration from the old Private-Talk Terminal, install, chat, exec refused, Tor, alternate port, ban persistence, doctor, port change, uninstall; it also builds and runs the Docker image.

```
main.go                     flags, health endpoint, graceful shutdown
install.sh                  one-line install / upgrade / uninstall (also vivant-ctl)
internal/chat/              rooms, identities, private messages, history, rate limits, bans, reports (no SSH)
internal/ui/term.go         full interface: small terminal renderer + key decoder
internal/ui/plain.go        line mode
internal/ui/format.go       message formatting, timezones, mentions, Chinese + English text
internal/server/            Wish SSH gateway, authentication, connection limits, ban persistence
cmd/vivant-bench/           load generator
deploy/                     systemd unit (generated by install.sh --print-unit), config example, offline installer builder
```

User-visible text (chat prompts, `/help`, key hints, installer and doctor output, `vivant -h`) is always written in both Simplified Chinese and English; source comments stay in English.

## Roadmap

- [x] SSH login without accounts, random nicknames, public rooms, private room codes, private messages, Chinese
- [x] Rate limits, admin tools, reports, ignoring, message expiry, privilege separation, systemd sandbox
- [x] One-line install / upgrade / uninstall, CI, automatic releases, load testing
- [x] Users never send public keys, address-free logs, Tor onion service
- [x] About 2000 full-interface users on one core
- [x] `/privacy` data policy, `/forget` erases your messages, no core dumps
- [x] Optional ban persistence, `/bans` and `/unban`
- [x] Unread counts across rooms, cross-room mention notices
- [x] Bell, collapsed join/leave lines, alternate port 443, fingerprint docs, shared limits for Tor exits
- [x] Renamed to VIVANT; interface always in Chinese and English
- [x] `vivant-ctl doctor` self-check
- [x] Per-connection read throttle, Docker image (GHCR)
- [x] Handshake timeout (30 s), well-known port warnings, external monitoring docs
- Not planned: end-to-end encryption inside the SSH chat itself. It would need a dedicated client on users' devices, which conflicts with "one ssh command and you're in".
